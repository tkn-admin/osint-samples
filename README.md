# osint-samples

個別企業のディープダイブ OSINT レポート (サンプル公開)。

EDINET (金融庁) / SEC EDGAR (米国) などの公開開示情報を、複数ソース横断で AI が整理し、
引用ソースと品質スコア (0〜100、緑/黄/赤) を明示してレポート化したものです。

公開ページ: [https://tkn-admin.github.io/osint-samples/](https://tkn-admin.github.io/osint-samples/)

## 収録サンプル (2026-05-25 時点)

- **任天堂 7974** (品質 59/100 中) — N 期 KPI 推移、Switch 2 後の業績変化
- **The Walt Disney Company (DIS)** (品質 65/100 中) — 8-K / Form 4 / 13D/G 横断
- **四国化成ホールディングス 4099** (品質 53/100 中) — 訂正有報の差分抽出

## ご留意事項

- 公開済の開示情報を整理した観察的分析であり、個別銘柄の売買推奨や将来の価格予測は含みません。
- 重要な判断には、レポート中に明示された一次資料 (EDINET / SEC) を必ず原文でご確認ください。
